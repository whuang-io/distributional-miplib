Maximum Independent Set

Problem Description

In an independent set (IS) problem, an undirected graph \(G=(V,E)\) in given. The goal is to select the largest subset of nodes such that no two nodes in the subsets are connected by an edge in \(G\): \[\max \sum_{v\in V} x_v \] \[\textrm{s.t.} x_u+x_v\leq 1, \,\forall (u,v)\in E, \] \[ x_v\in\{0,1\}, \, \forall v\in V.\] The graph \(G\) is typically a Erdos-Renyi or a Barabasi-Albert random graph.

Related literature

Learning to Branch

For learning to branch, IS has been used as a benchmark in [Gasse19, Gupta20]. Their generator could be found at Learn2Branch. For 1-hour runtime limit with SCIP, it is tested on IS instances on Barabasi-Albert random graphs with 500, 1,000 and 1,500 nodes and affinity set to 4. (Note that in [Gasse19, Gupta20, Wu21], the papers state the graphs are Erdos-Renyi random graphs. However, the source code indicates they are Barabasi-Albert graphs.)

Large Neighborhood Search

For large neighborhood search, IS has been used in [Wu21, Huang23, Huang23b]. Huang et al. [Huang23] use Erdos-Renyi graphs with 6,000 and 12,000 nodes and affinity set to 4.  Huang et al. In addition to the distributions complied in Distributional MIPLIB shown in the table above,  Wu et al. [Wu21] use Barabasi-Albert graphs with 1,500, 3,000 and 6,000 nodes and affinity set to 4.  [Huang23b] use Barabasi-Albert graphs with 9,000 nodes and affinity set to 5 to test a heuristic.
