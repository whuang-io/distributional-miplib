Seismic-Resilient Pipe Network Planning

Problem Description

Seismic-Resilient Pipe Network (SRPN) Planning is a network design problem, where the goal is to select and upgrade water pipes of a water network to earthquake-resilient ones to create a water network that will resist most earthquake risks and ensure water delivery to critical customers such as evacuation centers, hospitals, and police stations under earthquake risks. The network should also guarantee water service coverage within certain distances away from residential areas.

Formally, we are given: an undirected graph \(G=(V,E)\), a set of Steiner nodes \(C\) representing critical customers, water sources \(T\), coverage constraints \(R\) and \(\{S(r):r\in R\}\), the cost function on the edges \(c: E \rightarrow \mathbb{R}^{\geq 0}.\)

We want to find a set of edges \(E'\subseteq E\) with minimum cost \(\sum_{e\in E'}c(e)\), such that all \(u\in C\) and \(r\in R\) are satisfied. We say that a Steiner node \(u\in C\) is satisfied if in the induced subgraph of \(E'\), \(u\) is connected to a source in \(T\) and \(r\) is satisfied if there exists \(e\in E'\cap S(r)\) connected to a source in \(T\).

W.l.o.g., it is assumed that \(T\cap C=\emptyset\) and \(T\cap \{u: \exists (u,v)\in S(r)\}=\emptyset,\, \forall r\in R\).

Below is a Flow-based MILP formulation introduced by [Huang20]. \begin{align} &\min_{x,y,z}\sum_{(i,j)\in E}c(i,j)(x_{i,j}+x_{j,i})&\nonumber\\ &\sum_{e\in \delta^{-}(v)}y_e=\mathbf{1}_{[v\in C]}+\sum_{e\in \delta^{+}(v)}(y_e+x_e)&\forall v\in V\label{Con0}\\ &x_{i,j}+x_{j,i}\leq 1& \forall (i,j)\in E\label{Con1}\\ &\sum_{(i,j)\in S(r)}x_{i,j}+x_{j,i}\geq 1&\forall r\in R\label{Con2}\\ &0\leq y_e\leq (|\hat{E}|+|V|)x_e&\forall e\in \hat{E}\label{Con3}\\ % &0\leq y_{i,j}\leq (|\hat{E}|+|V|)z_j&\forall (i,j)\in \hat{E}\\ %&z_v=1&\forall v\in C\\ %&z_v\in\{0,1\} &\forall v\in V\\ &z+\sum_{t\in T}y_{0,t}=|\hat{E}|+|V|&\label{Con4}\\ &\sum_{t\in T}y_{0,t}=|C|+\sum_{e\in \hat{E}}x_{e}&\label{Con5}\\ &x_e\in\{0,1\}&\forall e\in \hat{E}\label{Con6} \end{align}
