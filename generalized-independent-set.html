Generalized Independent Set

Problem Description

The Generalized Independent Set Problem (GISP) is a graph optimization problem proposed for forestry management [Hochbaum97,Colombi17]. The input consists of a graph, a subset of removable edges with a removal cost, and a revenue for each vertex. The goal is to select a set of vertices and remove a subset of the removable edges so as to maximize the total revenue of the selected vertices minus the total cost of the removed edges, such that the selected vertices are independent in the graph after edge removal.

Notation

  • \(G=(V,E)\): undirected graph with vertex set \(V\) and edge set \(E\).
  • \(E' \subseteq E\): the set of removable edges. In the generator, each edge of \(E\) is made removable independently with probability \(\alpha\) (the removal probability).
  • \(r_v\): revenue of selecting vertex \(v\) (\(r_v = 100\) for all \(v\) in all distributions).
  • \(c_e\): cost of removing edge \(e \in E'\) (\(c_e = 1\) for all \(e\) in all distributions).
  • \(x_v \in \{0,1\}\): 1 if vertex \(v\) is selected.
  • \(y_e \in \{0,1\}\): 1 if removable edge \(e\) is removed.

MILP formulation [Colombi17]

\begin{align} \max_{x,y} \quad & \sum_{v \in V} r_v\, x_v - \sum_{e \in E'} c_e\, y_e \\ \text{s.t.} \quad & x_u + x_v \leq 1 && \forall \{u,v\} \in E \setminus E' \\ & x_u + x_v - y_{uv} \leq 1 && \forall \{u,v\} \in E' \\ & x_v \in \{0,1\} && \forall v \in V \\ & y_e \in \{0,1\} && \forall e \in E' \end{align}

The instance files state the equivalent minimization problem \(\min \sum_{e \in E'} c_e y_e - \sum_{v \in V} r_v x_v\). An instance has \(|V| + |E'|\) binary variables and \(|E|\) constraints (one per edge). The Erdős–Rényi distributions draw \(G\) from \(G(n,p)\); the Ext hard distribution uses fixed graphs from the DIMACS 1993 clique benchmark, following [Khalil17].

Related literature

Learning Primal Heuristics

GISP has been used as a benchmark in [Khalil17] for learning to schedule primal heuristics in MIP solving. There, 12 of the 1993 DIMACS challenge graphs are used to generate instances, with 20 random GISP instances generated for each graph. Edges are set to be in removable set E' with probability α=0.75. Edge costs are set to 1, and node rewards are 100.

Learning Backdoors

GISP has also been used as a benchmark in [Ferber22,Cai24] for learning backdoor sets in MIP. Graphs, problems are solved on Erdős–Rényi graphs with n nodes and edge probability p=0.3. In [Ferber22], edges are set to be removable with probability α=0.75, edge removal costs are set to 1, and node rewards are 100. Easy and hard instances have n=150 and n=175 nodes respectively. In [Cai24], edges are set to be removable with probability α=0.25.
