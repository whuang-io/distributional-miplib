Neural Network Verification

Problem Description

Neural Network Verification (NNV) via MILP is proposed in [Cheng17,Tjeng19] as a problem of verifying the robustness of a fixed neural network on a given input example. The goal is to determine what is the minimum perturbation of an input example required to switch the network's output from the correct class to an incorrect class. If this minimum perturbation exceeds a specified threshold, then the neural network is considered robust on that input example.

Inputs

  • Pre-trained neural network
  • Example input and label
  • Norm measuring example distance
  • Robustness threshold

The MILP formulation for NNV can be found in [Cheng17,Tjeng19] (Appendix A in [Tjeng19]).

Related Literature

The NNVerify benchmark has been used in several papers on learning for diving [Nair20], branching [Nair20], large neighborhood search [Sonnerat21], cuts [Paulus22], and backdoors [Ferber22]. It was originally generated and proposed in [Nair20] with that dataset being available online (Github repository ). The instances come from verifying a small convolutional network on all of the MNIST instances.  A description of generator was given in [Tjeng19] (Github repository) but there is no "ready-to-run" script.
