Distributional MIPLIB

The first comprehensive standardized dataset for evaluating ML-guided MILP methods

NEW: Distributional MIPLIB is now on Hugging Face [link] !

About

Distributional MIPLIB [arXiv Preprint] is the first comprehensive standardized dataset for evaluating ML-guided Mixed Integer Linear Programming (MILP) solving. It contains MILP distributions from 13 domains, classified into different hardness levels.

Background

MILP is a fundamental tool for modeling combinatorial optimization problems. Recently, a growing body of research has used ML to accelerate MILP solving. Despite the increasing popularity of this approach, there is a lack of a common repository that provides distributions of similar MILP instances across different domains, at different hardness levels, with standardized test sets. We curate MILP distributions from existing work in this area as well as real-world problems that have not been used.

Dataset Overview

The table below provides a summary of problem distributions. The links for downloading the distributions are provided in the webpage of each domain.

  • Instance Statistics

    • Average number of binary variables (# Var B)
    • Average number of integer variables (# Var I)
    • Average number of continuous variables (# Var C)
    • Average number of constraints (# Constr)

  • Performance metrics

    • Number of instances in the test set that are solved to optimality in 1 hour (# Opt). The number of test instances is 100, unless otherwise specified.
    • Average solving time in seconds for instances solved to optimality (Opt Time)
    • Average primal-dual gap after 1 hour for instances not solved to optimality (NonOpt Gap)
    • Primal-dual integral (Integral)

We use Gurobi (v10.0.3) with 1 hour time limit, on a cluster with Intel Xeon Silver 4116 CPUs @ 2.10GHz, with a RAM allocation of 5G. For SRPN-Hard, MMCN-Very Hard, WF_OTS_UG-Hard and EXAM instances that had memory errors at 5GB, we increased the RAM to 15G.
