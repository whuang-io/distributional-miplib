Minimum Vertex Cover

Problem Description

In a minimum vertex cover (MVC) problem, an undirected graph \(G=(V,E)\) is given, with a nonnegative weight on each node. The goal is to select a subset of nodes of minimum total weight such that at least one end point of every edge in the graph is selected.

All levels are generated on Barabási-Albert random graphs with the generator of [Huang23] (based on the generator of [Song20]; the easy, medium and hard levels are new and use the same code with different parameters). A graph with \(|V|\) nodes and affinity \(m_{BA}\) (each new node attaches to \(m_{BA}\) existing nodes) has exactly \(m_{BA}(|V|-m_{BA})\) edges. Node weights are drawn independently and uniformly from \([0,1]\), so the instances are weighted vertex cover problems.

Notation.

  • \(G=(V,E)\): undirected Barabási-Albert graph.
  • \(w_v\sim U[0,1]\): weight of node \(v\in V\).
  • \(x_v\in\{0,1\}\): 1 if node \(v\) is in the cover.

Formulation.

\begin{align} \min\ & \sum_{v\in V} w_v x_v \\ \textrm{s.t.}\ & x_u+x_v\geq 1, && \forall (u,v)\in E, \\ & x_v\in\{0,1\}, && \forall v\in V. \end{align}

There is one constraint per edge, so the number of constraints is \(|E|=m_{BA}(|V|-m_{BA})\).

Related literature

Large Neighborhood Search

For large neighborhood search, Huang et al. [Huang23] use Barabasi-Albert graphs with 1,000 and 2,000 nodes and affinity set to 70. The set of instances with 1000 nodes was used for training. The set of instances with 2000 nodes was used as an out-of-distribution test set. MVC has been used in [Song20, Huang23, Huang23b].  In addition to the distributions complied in Distributional MIPLIB shown in the table above, Song et al. [Song20] use both Erdos-Renyi and Barabasi-Albert graphs with 1,000 nodes and affinity set to 4. Huang et al. [Huang23b] use the Very hard 3 distribution (Barabasi-Albert graphs with 9,000 nodes and affinity set to 5) to test a heuristic.

Backdoor

For learning backdoors, MVC has been used as a benchmark in [Cai25], which trains on Barabasi-Albert graphs with 1,500 nodes and affinity set to 5, and tests on graphs of the same size as well as on larger graphs with 2,000 nodes and affinity set to 5 (the Medium distribution in Distributional MIPLIB).

Predict-and-Search

For predict-and-search, MVC has been used as a benchmark in [Huang24] and [Cai25], which train on Barabasi-Albert graphs with 6,000 nodes and affinity set to 5, and test on graphs of the same size as well as on larger graphs with 9,000 nodes and affinity set to 5 (the Very hard 3 distribution in Distributional MIPLIB).
