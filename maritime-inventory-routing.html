Maritime Inventory Routing

Problem Description

The Maritime Inventory Routing Problem (MIRP) arises from global bulk shipping and involves both ship routing and inventory management. The problem not only determines routes from production ports to consumption ports to minimize transportation costs but also manages the inventory at these ports [Papageorgiou14].  [Papageorgiou14] introduced a mixed-integer programming model of this problem class and developed a library of publicly available test instances (MIRPLib).

Related Literature

A curated set of MIRP instances have been used as a hidden test set in the Machine Learning for Combinatorial Optimization Competition (ML4CO) [Gasse22].   We included this benchmark in Distributional MIPLIB and provide the statistics. We adhered to the train, validation, and test split established in ML4CO.  A larger set of MIRP instances is also available at the MIRPLIB [Papageorgiou14] (link).
