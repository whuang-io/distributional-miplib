Set Covering

Problem Description

In an set covering (SC) instance, we are given \(m\) elements and a collection \(S\) of \(n\) sets whose union is the set of all elements. The goal is to select a minimum number of sets from \(S\) such that the union of the selected set is still the set of all elements: \[\min \sum_{s\in S} x_s \] \[\textrm{s.t.} \sum_{s\in S: i\in s} x_s \geq 1, \,\forall i\in[m],\] \[ x_s\in\{0,1\}, \, \forall s\in S.\]

Related Literature

Learning to Branch

For learning to branch, SC has been used as a benchmark in [Gasse19, Gupta20] where their generator could be found here. In addition, Ecole has a generator for SC instances that allows customized problem parameters. For 1-hour runtime limit with SCIP, the typical problem sizes that have been used range from 500 to 2,000 sets with 1,000 elements.

Large Neighborhood Search (LNS)

For large neighborhood search, CA has been used in [Wu21, Huang23, Huang23b]. For 1-hour runtime limit,  the typical problem sizes that have been used range from 1,000 to 8,000 sets with 5,000 elements.
