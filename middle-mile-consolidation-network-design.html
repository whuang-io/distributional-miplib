Middle-Mile Consolidation Network Design

Problem Description

The Middle-Mile Consolidation Network (MMCN) design problem [Greening23] considers a shipper that needs to transport a set of commodities \( \mathcal{K}\) from known origins to known destinations. Let \((\mathcal{N}, \mathcal{A})\) define the shipper's service network. The node set \(\mathcal{N}\) denotes the set of facilities in the network, which include vendors, fulfillment centers (FCs), and last-mile delivery (LMDs) centers. In this problem, both vendors and FCs act as origins and LMDs are the destinations; FCs also act as cross-docks for consolidation. The directed arc set \(\mathcal{A}\) consists of the set of potential freight transportation arcs connecting pairs of locations. The set is composed of vendor-to-LMD (or ''directs''), vendor-to-FC, FC-to-FC, and FC-to-LMD arcs.

The MMCN design problem determines a minimum-cost allocation of transportation capacity on network arcs to ensure that a shipment consolidation plan is feasible. This includes the decision as to whether to send demand via the middle-mile consolidation network (i.e., use FCs as cross-docks for consolidation) or send demand directly from vendor to LMD centers.

The proposed MILP model uses a path-based, flat (not time-expanded) network representation of capacity allocation to arcs and an associated representation of shipment consolidation into load dispatches. Freight transportation capacity decisions are modeled as frequencies of load dispatches on arcs per time (e.g., per week). The demand inputs then are also expressed as constant rates per time (e.g., pounds per week).

Although many shipments may be sent over time for an origin-destination pair, or commodity \(k \in \mathcal{K}\), the model assumes that each such shipment follows the same sequence of arcs (or path) defined by the chosen consolidation plan. The full formulation for this problem can be found at formulation, which was kindly provided by Lacy Greening.

Instances Distribution

The hardness level of the MMCN problems depends on the network size. We include instances created from different network size groups specified by [Greening23].  We include distributions containing binary and integer variables (denoted as BI) and distributions containing binary and continuous variables (denoted as BC). BI and BC distributions correspond to 2 variants of MMCN. BI distributions correspond to the Single-Mode (SM) variant, where all arcs in the network have the same single transit mode. BC distributions correspond to the Multi-Mode (MM) variant, where multiple transit modes are allowed. For each variant, we provide instances of different difficulty levels.
